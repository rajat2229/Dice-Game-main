
# Dice-Game

A simple HTML, CSS, and JavaScript-based game where two players roll a dice, accumulate points, and try to reach 50 points first.

## Game Rules

* **Player 1 always has an advantage of rolling the dice first.** <img src="images/image1.jpg" alt="Player 1 rolls dice first" />

* **Each dice roll will add your score to the current score.** <img src="images/image3.jpg" alt="Dice roll adds score" />

* **The Hold button shifts all your current score to the final score and changes the turn.** <img src="images/image4.jpg" alt="Hold button" />

* **If the dice roll results in 1, your current score becomes zero and the turn changes.** <img src="images/image5.jpg" alt="Dice roll results in 1" />

* **The player who reaches 50 points first will win the game.** <img src="images/image6.jpg" alt="Winner Player" />

## Installation

1. Clone the repository to your local machine using:

   ```bash
   git clone https://github.com/rajat2229/Dice-Game-main.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Dice-Game-main
   ```

3. Open `index.html` in a web browser to play the game.

## Usage

* **Roll Dice:** Click the "🎲 Roll dice" button to roll the dice and accumulate points.
* **Hold:** Click the "📥 Hold" button to transfer your current points to the final score and end your turn.
* **New Game:** Click the "🔄 New game" button to reset the game and start fresh.
* **Game Rules:** Click the "❓ Game Rules" button to view the rules of the game in a modal.
